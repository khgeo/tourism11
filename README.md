# ទេសចរណ៍ ថ្នាក់ទី១១ · មេរៀនអន្តរកម្ម

គេហទំព័រមេរៀនអន្តរកម្មមុខវិជ្ជាទេសចរណ៍ ថ្នាក់ទី១១ (១២មេរៀន · ៣៤ម៉ោង) សម្រាប់សិស្សរៀនលើទូរស័ព្ទ ឬកុំព្យូទ័រ។

## មានអ្វីខ្លះ
- **១២មេរៀន** — គោលបំណង អត្ថបទមេរៀនលម្អិតដូចសៀវភៅ រូបថតពី Wikimedia Commons infographic ចំណុចត្រូវចងចាំ សំណួរពិភាក្សា
- **ល្បែង** — តម្រៀប ផ្គូផ្គង រៀបលំដាប់ កាតត្រឡប់ ស្ថានការណ៍បដិសណ្ឋារកិច្ច
- **ឧបករណ៍** — ផែនទីទេសចរណ៍កម្ពុជា · រចនាកញ្ចប់ដំណើរ · ប្រាក់ទេសចរទៅណា? · វាយតម្លៃសាលាស្អាត · គណនាប្លាស្ទិច
- **តេស្ត** មេរៀននីមួយៗ + តេស្តរំលឹកឆមាសទី១ និងទី២ (សំណួរចៃដន្យ)
- **លិខិតឆ្លងដែនទេសចរ** — សិស្សទទួលត្រា ពេលតេស្តបាន ≥៧០% (បោះពុម្ពបាន)
- **កិច្ចតែងការបង្រៀន** — ផែនការប្រចាំឆ្នាំ និងម៉ោងទាំង៣៤ (ផ្ទាំង «📋» ក្នុងមេរៀននីមួយៗ និងទំព័រ #/plan) ទាញយកជា Word/PDF ក្នុងថត `plan/`
- **ស្លាយ PowerPoint ១ឯកសារ/មេរៀន** (A4 ផ្តេក សម្រាប់បោះពុម្ព ឬផ្ញើទូរស័ព្ទ) ក្នុងថត `plan/slides/` — មានកាតសម្រាប់កាត់ តេស្តកាត ABCD និងកំណត់ចំណាំគ្រូ
- **កាតវាក្យសព្ទ** ខ្មែរ–អង់គ្លេស និង **ទំព័រគ្រូ** (QR code សម្រាប់ចែកសិស្ស)

គ្មានការចុះឈ្មោះ គ្មាន server។ វឌ្ឍនភាពរក្សាទុកក្នុង browser របស់សិស្សម្នាក់ៗ។

## បោះផ្សាយលើ GitHub Pages
1. ចូល github.com → **New repository** → ដាក់ឈ្មោះ ឧ. `tourism11` → **Public** → Create
2. ចុច **Add file → Upload files** → អូសឯកសារ និងថតទាំងអស់ក្នុងថតនេះ (index.html, css, js, assets, README.md, .nojekyll) → **Commit changes**
3. ចូល **Settings → Pages** → Source: **Deploy from a branch** → Branch: `main` / `(root)` → **Save**
4. រង់ចាំ ១-២ នាទី។ តំណនឹងមានទម្រង់ `https://<username>.github.io/tourism11/`

## កែប្រែខ្លឹមសារ
ខ្លឹមសារទាំងអស់ (អត្ថបទ សំណួរ ចម្លើយ វីដេអូ តំណ ទីតាំងផែនទី វាក្យសព្ទ) នៅក្នុង **`js/data.js`**។
- `a: 2` ក្នុងសំណួរ មានន័យថាចម្លើយត្រូវគឺជម្រើសទី៣ (រាប់ពី ០)
- `b: 1` ក្នុងល្បែងតម្រៀប មានន័យថាប្រអប់ទី២ (រាប់ពី ០)
- `SITE.passScore` = ពិន្ទុ % សម្រាប់ទទួលត្រា

កែលើ GitHub ដោយចុចលើឯកសារ → ✏️ → Commit។ គេហទំព័រធ្វើបច្ចុប្បន្នភាពស្វ័យប្រវត្តិ។

អត្ថបទមេរៀន (យកតាមសៀវភៅទេសចរណ៍ថ្នាក់ទី១១ រួមទាំងមេរៀនសង្ខេប និងសំណួរ) និងរូបភាព នៅក្នុង `js/readings.js` (`imgs[].f` = ឈ្មោះឯកសារលើ commons.wikimedia.org)។ ប្រភពរូបភាពទាំងអស់មាននៅទំព័រ #/credits។

កិច្ចតែងការបង្រៀនលើគេហទំព័រ នៅក្នុង `js/plans.js` (បង្កើតពីឯកសារ Word)។ បើកែឯកសារ Word ត្រូវប្តូរឯកសារក្នុងថត `plan/` ផង។
